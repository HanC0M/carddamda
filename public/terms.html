1. 서비스 목적

카드담다는 이용자가 여러 TCG 카드 구매 후보를 빠르게 검색하고 외부 판매 페이지로 이동할 수 있도록 돕는 구매 세션 보조 도구입니다.

2. 외부 상품 정보

  • 카드담다는 외부 쇼핑 검색 API와 외부 판매 페이지 정보를 활용합니다.
  • 상품 가격, 재고, 판매 상태, 배송 조건은 실시간으로 달라질 수 있으며 최종 확인은 외부 판매 페이지에서 해야 합니다.
  • 카드담다는 외부 판매자, 결제, 배송, 환불, 교환을 직접 제공하지 않습니다.

3. 이용자의 책임

  • 이용자는 검색어, 키워드 개선 제안, 건의 내용을 사실에 맞게 입력해야 합니다.
  • 타인을 비방하거나 서비스 운영을 방해하는 내용을 제출해서는 안 됩니다.

4. 서비스 변경 및 중단

카드담다는 안정적인 운영, 기능 개선, 외부 API 변경, 기술적 사유에 따라 서비스의 일부 또는 전부를 변경하거나 중단할 수 있습니다.

5. 면책
